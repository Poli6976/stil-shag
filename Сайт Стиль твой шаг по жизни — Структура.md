# Структура сайта «Стиль — твой шаг по жизни»

> Основа: скилл **stylist** (5-шаговая консультация + слои образа + формат вывода) и бизнес-модель: **покупка вещи у партнёра-ЧП (по ссылке с сайта или переданная магазином на сайт) → онлайн-стилист собирает вокруг неё полный образ — это и есть «примерка»**. 1-я примерка (к 1-й покупке) — бесплатна, 2-я и далее (к следующим покупкам) — со скидкой 50%.

---

## 0. Логика проекта одним предложением

Женщина покупает вещь в магазине-партнёре (по ссылке с сайта или магазин сам передаёт данные о покупке на сайт), приходит на сайт с этой покупкой, и стилист (логика из скилла) собирает вокруг неё полный образ по слоям — это и называется «примеркой». К первой покупке примерка бесплатна, ко всем следующим — со скидкой 50%.

Это значит, что скилл — не «одна страница сайта», а **движок**, который работает в трёх точках:
1. на странице подбора образа (диалог по шагам),
2. в личном кабинете (гардероб, история, рекомендации при повторных визитах),
3. в блоге/базе знаний (готовые статьи «от эксперта» — то, что в скилле названо «автор статей и материалов о стиле»).

## 2. Разбор ключевых страниц

### 2.1 Главная — визитка
Задача: за 5 секунд объяснить «что это» и повести дальше, а не продавать в лоб.

Блоки:
- **Хедер**: логотип, слоган «Стиль — твой шаг по жизни», меню, кнопка «Подобрать образ».
- **Экран-обещание**: 1 фраза о сути (подбор образа под вас — фигуру, повод, бюджет), кнопка CTA.
- **Как это работает** (кратко, 3 иконки: Спросите → Получите образ → Купите со скидкой), ссылка «подробнее» → на страницу 2.
- **Для кого** — блок сегментов: «Для себя / Для дочери / Для подруги» (это прямо из примера в тексте скилла).
- **Примеры образов** — 3–4 карточки «было / стало» (текстовые описания + честные фото товаров, без выдачи чужих/сген. фото за реальные — ограничение из скилла).
- **Магазины-партнёры** — логотипы/бейджи (доверие).
- **Условия «Примерки»** коротко: 1-я бесплатно, далее −50%.
- **Отзывы** (коротко, без интимных деталей).
- **Футер**: юр. страницы, контакты, соцсети.

### 2.2 «Как это работает» — инструкция
Это отдельная страница, потому что механика нестандартная (примерка ≠ покупка одежды напрямую). Обязательно объяснить **до** того, как человек попадёт в диалог со стилистом.

Блоки:
- Пошаговая схема (лучше визуально, шаги как в скилле, но языком для клиента):
  1. Купите вещь у магазина-партнёра — по ссылке с сайта, либо магазин сам передаёт данные о вашей покупке на сайт.
  2. Придите на сайт с этой покупкой и начните примерку — расскажите о вещи (текст/фото/ссылка на заказ).
  3. Ответьте на несколько вопросов стилиста — по одному за раз.
  4. Получите полный образ по слоям вокруг купленной вещи, с объяснением «почему так».
  5. Первая примерка — бесплатно. Вторая и все следующие (к новым покупкам) — со скидкой 50%.
- **Явное определение «примерки»**: это не примерка одежды руками и не то, что предшествует покупке. Примерка — онлайн-услуга стилиста: **подбор полного образа вокруг уже купленной вещи** (по фото/параметрам/данным заказа). Это нужно написать прямым текстом на первом экране, иначе люди будут ждать, что сначала «примерят», а потом купят.
- Мини-FAQ на этой же странице (3–4 вопроса) со ссылкой на полный FAQ.
- Кнопка «Начать подбор образа».

### 2.3 Онлайн-стилист — ядро (движок скилла)
Здесь скилл разворачивается «как есть», пошагово, но в виде интерфейса, а не текстового чата целиком.

**3.1 Быстрый старт**
- Поле «Какую вещь вы купили?» — текст и/или загрузка фото, при наличии — ссылка на заказ/магазин (или вещь уже подгружена автоматически, если магазин передал данные о покупке на сайт).
- Переключатель «Это для меня / для дочери / для подруги» (прямо из примера скилла).
- Если фото — согласие на обработку фото (чекбокс, ссылка на политику конфиденциальности).

**3.2 Диалог-анкета**
- Реализация принципа «один вопрос за раз» из скилла: пошаговый визард, не одна длинная форма.
- Вопросы по очереди: пол/возрастная группа → повод (офис/прогулка/вечер/мероприятие) → бюджет → что уже есть в гардеробе → рост/вес/размер (опционально, с пометкой «можно пропустить») → предпочтения по стилю (классика/кэжуал/смело).
- Если формулировки похожи на подростковые или указан возраст до 18 — автоматически включается «подростковый режим» (без разбора фигуры, без вечерних/облегающих образов) — это прямое требование скилла, критично реализовать технически, а не только в тексте.

**3.3 Результат — образ по слоям**
Показывается ровно в формате вывода скилла, но как карточки/секции:
- 🎯 Повод и отправная точка
- 👕 Образ по слоям: верх / низ / верхняя одежда / обувь / аксессуары / причёска / макияж (если уместно)
- 💡 Почему именно так (логика по силуэту/цвету)
- 🛍 Что докупить — приоритетный список

**3.4 Что докупить**
- Каждая позиция — карточка товара со ссылкой на конкретный магазин-партнёр (ЧП), ценой и статусом: «1-я покупка — бесплатная примерка» либо «у вас скидка 50% на следующую примерку».
- Кнопка «Перейти в магазин» — с пометкой, что переход и покупка фиксируются для начисления скидки (важно для доверия и для юридической чистоты — предупредить заранее).

### 2.4 Личный кабинет
- **Мой гардероб** — чек-лист «что есть / чего не хватает / что купить в первую очередь» (это прямая функция «гардероб.md» из скилла, только в виде интерфейса).
- **История образов** — все прошлые подборы, к ним можно вернуться.
- **Мои примерки и скидки** — счётчик: сколько покупок совершено через сайт, статус текущей скидки (бесплатно / −50% / обычная цена), история использования.
- **Избранное** — сохранённые товары/образы.

### 2.5 Магазины-партнёры
- Каталог ЧП с фильтрами (категория: одежда/обувь/аксессуары/головные уборы), карточка магазина (что продают, условия доставки/возврата — ссылка на их собственные правила, не сайта).
- Важно: сайт не является продавцом, поэтому здесь нужен явный дисклеймер об ответственности (продавец — ЧП, сайт — посредник/агрегатор рекомендаций).

### 2.6 Программа «Примерка» — правила
Отдельная страница-оферта, где чётко, юридически внятно прописано:
- что считается «примеркой»: онлайн-услуга стилиста по сборке полного образа вокруг вещи, которая уже куплена у партнёра;
- что считается «засчитываемой покупкой»: **любая покупка по представленным на сайте ссылкам магазинов, а также покупка, о которой магазин сам передал данные на сайт** — не важно, какой именно партнёр, счёт общий по пользователю;
- как считается очередь: 1-я покупка (по счёту у конкретного пользователя) → примерка бесплатно; 2-я и каждая следующая → примерка со скидкой 50%;
- есть ли лимит на количество примерок со скидкой, срок действия скидки;
- что происходит при возврате товара партнёру (скидка/бесплатная примерка отзывается или нет).

Это нужно обязательно продумать заранее — иначе пользователи и партнёры будут спорить об начислении скидок.

### 2.7 База знаний / Блог
Реализация роли «автор статей и материалов о стиле» из скилла:
- статьи по цветотипам, трендам по сезонам, разбору фигур (для взрослых), базовому гардеробу;
- отдельный раздел для родителей/подростков — только про повод, комфорт, цвет — без темы фигуры (по ограничению скилла).
- это же SEO-трафик на сайт.

### 2.8 О проекте
- Идея проекта: помочь женщине точно понимать, что, для чего и когда надевать, и не ошибаться с покупками у партнёров.
- Как устроена консультация (кратко, без лишней «легенды» — по сути дела: подход, методика, принципы подбора).
- Магазины-партнёры и условия сотрудничества.
- Контакты и поддержка.

### 2.9 FAQ / Помощь
Минимум блоков, которые снимут 80% вопросов:
- Это платно?
- Что такое «примерка»? — Это подбор полного образа стилистом вокруг вещи, которую вы уже купили у партнёра. Не путать с примеркой одежды руками в магазине.
- Нужно ли сначала что-то купить, чтобы сделать примерку? — Да, примерка делается к уже купленной вещи.
- Как считается скидка, если я покупаю в разных магазинах? — Учитывается любая покупка по ссылкам магазинов, представленным на сайте, а также покупка, о которой магазин сам передал данные на сайт. Считается общий счёт покупок пользователя, независимо от того, в каком именно магазине-партнёре куплена вещь: 1-я покупка — примерка бесплатно, 2-я и далее — скидка 50%.
- Вы храните мои фото и параметры тела? Как их удалить? — Вы можете в любой момент удалить введённые вами данные сами, а по завершении примерки — удалить всю информацию по этой примерке целиком.
- Могу я задать вопрос за дочь/подругу?
- Что если ничего из предложенного не понравилось?
- Есть ли версия для мужчин/подростков?

### 2.10 Юридические страницы (обязательны, часто забывают)
- **Пользовательское соглашение** — что сайт агрегатор/консультационный сервис, не продавец.
- **Политика конфиденциальности** — отдельно прописать обработку фото и физических параметров (рост/вес/размер) — это чувствительные данные, нужна явная форма согласия при загрузке.
- **Публичная оферта / Правила программы «Примерка»** — юридическая версия раздела 2.6.
- **Партнёрское соглашение для ЧП** — как магазины подключаются, как подтверждают покупки, как передают данные о продаже для начисления скидки.

### 2.11 Отзывы / До-После
- Разрешено использовать реальные фото одежды на человеке/манекене (это прямо допущено в тексте скилла), но:
  - нельзя выдавать сгенерированные образы за реальные фото пользователей;
  - нужно согласие пользователя на публикацию его отзыва/фото, если это её реальное фото.

## 4. Что ещё обязательно добавить, чтобы всё было понятно

1. **Явное определение «примерки» на первом же экране инструкции** — иначе пользователи будут думать, что это офлайн-примерка одежды, и разочаруются.
2. **Прозрачная механика скидок** — отдельная понятная схема/таблица (1-я покупка → бесплатно, 2+ → −50%), видимая и в кабинете, и в правилах.
3. **Статус выполнения** в личном кабинете — «у вас использована бесплатная примерка» / «доступна скидка 50%» — иначе люди не поймут, на каком они этапе.
4. **Дисклеймер об ответственности продавца** — сайт не отвечает за качество/доставку/возврат товара ЧП, это отдельно на каждой карточке магазина.
5. **Форма согласия на обработку фото и параметров тела** — обязательна юридически и по духу скилла (чувствительные данные).
6. **Подтверждение покупки** — механизм, как сайт узнаёт, что покупка совершена (промокод от партнёра, отметка в кабинете, чек) — без этого скидочная система не работает технически.
7. **Ограничение по возрасту при регистрации/входе** — чтобы подростковый режим включался автоматически, а не по желанию.
8. **Простая онбординг-подсказка** при первом входе в «Онлайн-стилист» (3 экрана: как это работает, что вводить, что получите).
9. **Раздел для партнёров-ЧП** (можно минимальный, отдельная страница «Стать партнёром») — если магазины должны сами размещать ссылки/подтверждать продажи.
10. **Политика хранения и удаления данных** — две возможности в кабинете: удалить отдельно введённые данные (в любой момент по своему выбору) и удалить все данные по конкретной примерке целиком после её завершения.
11. **Мобильная версия/адаптивность** — сценарий использования («женщина фотографирует юбку и тут же спрашивает совета») в основном мобильный.

## 5. Возможный порядок реализации (MVP → расширение)

**MVP (женская аудитория, как в запросе):**
Главная → Как это работает → Онлайн-стилист (быстрый старт + анкета + результат) → карточки товаров с ссылками на 1–2 пилотных магазина-партнёра → простой личный кабинет (гардероб + статус скидки) → правила программы «Примерка» → юр. страницы.

**Этап 2:**
Блог/база знаний, каталог всех партнёров, отзывы/до-после, расширенный кабинет (история образов, избранное).

**Этап 3 (по тексту скилла — уже заложено в логике, но не в этом запросе):**
Мужской и подростковый разделы с отдельными сценариями (без разбора фигуры для подростков).

## 6. Какие инструменты нужны для работы сайта

Да, без них система не заработает технически — вот минимальный набор по функциональным блокам.

| Задача | Что нужно | Зачем |
|---|---|---|
| **Сам сайт** | Хостинг + движок сайта (CMS вроде Tilda/WordPress для старта, либо кастомная разработка на этапе роста) | Основа, на которой всё строится |
| **Личный кабинет и авторизация** | Модуль регистрации/входа (email или телефон, желательно с подтверждением возраста) | Хранение истории, гардероба, статуса скидок; автоматическое включение «подросткового режима» |
| **Диалог-анкета стилиста** | Конструктор форм-визардов (пошаговый опрос по одному вопросу) — либо готовый сервис форм, либо кастомный модуль | Реализация принципа «один вопрос за раз» из скилла |
| **«Мозг» стилиста** | Подключение к языковой модели (например, через API) для генерации самой консультации/образа по вашему скиллу | Это и есть движок, который формирует результат по формату из скилла |
| **Загрузка и хранение фото** | Облачное хранилище с ограничением доступа + модерация загружаемых фото | Чувствительные данные (фото вещи/человека), нужна защита и возможность удаления |
| **Учёт покупок и скидок** | Система промокодов/UTM-меток на ссылках в магазины + личный кабинет партнёра (или хотя бы форма) для подтверждения покупок | Без этого не отследить «1-я покупка / 2-я покупка» и не начислить скидку |
| **Каталог магазинов-партнёров** | Простая база данных (карточки магазинов и товаров), с возможностью партнёрам самим добавлять/обновлять ссылки | Актуальность ссылок и цен |
| **Оплата (если сама примерка станет платной для части пользователей)** | Платёжный шлюз (эквайринг) | Приём оплаты за примерку со скидкой, если это будет не бесплатно |
| **Аналитика** | Веб-аналитика (счётчик посещений, воронка от «начал примерку» до «перешёл в магазин») | Понимать, где пользователи уходят, и улучшать сайт |
| **Уведомления** | Email/SMS или push-рассылка | Напоминания о статусе примерки, новых скидках, брошенной анкете |
| **Юридический блок** | Готовые шаблоны документов (оферта, политика конфиденциальности) — адаптировать под вашу схему скидок | Без этого схема со скидками и хранением фото юридически уязвима |

Для самого старта (MVP) минимально достаточно: конструктор сайта/CMS + форма-визард + подключение к языковой модели по API + простая таблица/база для учёта покупок и промокодов + базовая аналитика. Остальное (платёжный шлюз, полноценный кабинет партнёра, SMS-рассылки) можно добавлять по мере роста.
