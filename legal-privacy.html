Политика конфиденциальности

1. Какие данные мы собираем

  • Данные анкеты подбора образа: повод, бюджет, стиль, что уже есть в гардеробе.
  • По желанию — рост и размер (вопрос всегда помечен как необязательный).
  • Описание и/или фото вещи, вокруг которой собирается образ (фото — по желанию, для автоматического разбора), и, если есть, ссылка на заказ у Партнёра.
  • Технические данные использования Сайта (для аналитики и стабильности сервиса).
  • Email — при входе в личный кабинет (для отправки одноразовой ссылки для входа), а также связанные с аккаунтом баланс и история пополнений.

2. Особый режим для фото и физических параметров

Мы считаем фото и параметры тела чувствительными данными. Они обрабатываются только с явного согласия — при загрузке фото или заполнении этих полей будет отдельный чекбокс согласия — и используются исключительно для подбора образа.

Фото вещи технически обрабатывается сервисом распознавания изображений GigaChat (Сбер) — это единственный получатель фото, и только для того, чтобы описать вещь (тип, цвет, крой, ткань). Фото не сохраняется на нашей стороне: оно передаётся в GigaChat для разбора и не остаётся ни в базе данных, ни в логах после ответа. Мы не передаём эти данные никаким другим третьим лицам и не используем их для целей, не связанных с Примеркой.

Данные личного кабинета — email, вход, баланс и история пополнений — хранятся у технического партнёра Supabase Inc. (облачная база данных и сервис авторизации). Это единственный получатель этих данных, необходимый для работы личного кабинета и оплаты услуг.

Результат «Образа по фото» — готовая иллюстрация и текстовое описание по слоям — сохраняется в разделе «Мои образы» личного кабинета и привязан к вашему аккаунту. Само исходное фото (селфи), по которому строится образ, при этом по-прежнему нигде не остаётся — см. абзац выше: оно уходит только в GigaChat для разбора. Доступ к сохранённым картинкам — только по временной ссылке, которая действует несколько минут и запрашивается заново при каждом открытии кабинета; открытой постоянной ссылки на картинку не существует. Удалить любой сохранённый образ можно в любой момент кнопкой «Удалить» в том же разделе — удаление необратимо и стирает и картинку, и текст.

При пополнении депозита оплата картой проходит на стороне платёжного оператора Robokassa — номер карты и CVC не попадают на Сайт и не сохраняются нами. Robokassa передаёт Сайту только факт и сумму оплаты, необходимые для зачисления депозита.

На время, пока приём карт проходит проверку, доступен временный способ оплаты — перевод по Системе быстрых платежей (СБП) напрямую владельцу Сайта. В этом случае реквизиты перевода (номер телефона получателя) видны только в личном кабинете при выборе этого способа, а подтверждение поступления делает вручную владелец Сайта, сверяя перевод в своём банковском приложении с указанной суммой и кодом заказа. Данные банковской карты или счёта отправителя Сайту не передаются и не сохраняются — виден только факт и сумма перевода.

3. Подростковый режим

Если пользователю меньше 18 лет, вопросы о фигуре и физических параметрах не задаются вовсе — это техническое ограничение, а не только текстовая рекомендация.

4. Сколько хранятся данные

Анкета подбора образа нигде не сохраняется — она существует только во время сессии в браузере. Исходное фото не сохраняется вовсе (см. пункт 2). Результаты «Образа по фото» (иллюстрация и текст) хранятся в разделе «Мои образы» личного кабинета, пока вы сами их не удалите — срока автоматического хранения нет. Данные личного кабинета (email, баланс, история операций, а также оставшиеся к тому моменту сохранённые образы) хранятся, пока у вас есть аккаунт, и удаляются в течение 7 дней после вашего запроса на andr3y2065y@gmail.com.

5. Ваши права

  • Удалить введённые данные в любой момент по своему выбору.
  • Удалить любой сохранённый образ — кнопкой «Удалить» в разделе «Мои образы» личного кабинета, без обращения к нам. Удаление происходит сразу и необратимо.
  • По завершении Примерки — удалить всю информацию по ней целиком.
  • Демо-версия гардероба и статуса примерок (без входа) хранит данные только в браузере (localStorage) — их можно удалить, очистив данные сайта в настройках браузера, без обращения к нам.

6. Партнёры

Чтобы засчитать покупку в Программе «Примерка», Партнёру передаётся минимально необходимая информация — факт покупки и данные, нужные для её подтверждения. Содержание вашей Примерки (ответы анкеты, образ) Партнёрам не передаётся.

7. Технические данные и аналитика

Сейчас Сайт не использует внешнюю веб-аналитику (Яндекс.Метрику, Google Analytics и т. п.). Технически необходимое хранилище в браузере используется только для поддержания вашего входа в личный кабинет (сервис авторизации Supabase) — без него вход не будет работать. Если в будущем появится аналитика, этот раздел будет обновлён заранее.
