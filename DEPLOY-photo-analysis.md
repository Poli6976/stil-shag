# Как включить разбор фото вещи (GigaChat)

Код готов (`api/analyze-item.js`), но чтобы он реально заработал, нужно:
1. Получить доступ к GigaChat API
2. Задеплоить сайт туда, где может выполняться серверный код (сейчас — просто статика на `python -m http.server`, там `/api` не работает)
3. Прописать ключ

Ниже — по шагам, без технического жаргона там, где можно было его избежать.

---

## 1. Получить ключ GigaChat API

1. Зайти на [developers.sber.ru](https://developers.sber.ru), войти/зарегистрироваться (можно через Сбер ID).
2. Создать проект **«GigaChat API»**.
3. Выбрать тариф — для самозанятого это **физлицо** (`GIGACHAT_API_PERS`). Есть бесплатный лимит на старте (по документации — около 1 млн токенов в год), для теста хватит с большим запасом.
4. В разделе **«Авторизационные данные»** сгенерировать **Authorization key** — это длинная строка, она и есть `GIGACHAT_AUTH_KEY`. Никому её не показывать и не публиковать.

## 2. Завести аккаунт на Vercel и подключить сайт

Vercel выбран потому, что он бесплатно и без лишней настройки размещает и статические файлы, и такие серверные функции, как `api/analyze-item.js` — больше в проекте ничего менять не пришлось.

1. Зарегистрироваться на [vercel.com](https://vercel.com) (можно через GitHub).
2. Если папки проекта ещё нет на GitHub — создать там репозиторий и загрузить в него все файлы папки `Проект СТИЛЬ` (через GitHub Desktop или `git`, если это не близко — можно попросить сделать это на созвоне/отдельным шагом).
3. На Vercel: **Add New → Project → Import** свой GitHub-репозиторий. Framework Preset можно оставить «Other» — конфигурация не нужна, Vercel сам увидит `api/` и статические файлы.

## 3. Прописать переменные окружения

В Vercel: **Project → Settings → Environment Variables**, добавить:

| Имя | Значение |
|---|---|
| `GIGACHAT_AUTH_KEY` | ключ из шага 1 |
| `GIGACHAT_SCOPE` | `GIGACHAT_API_PERS` |
| `GIGACHAT_MODEL` | `GigaChat` (можно оставить пустым — подставится само) |

Сохранить → **Redeploy** (передеплой), чтобы переменные подхватились.

## 4. Проверить

Открыть свою страницу `.../online-stylist.html` на реальном Vercel-адресе (не на localhost), на первом шаге визарда нажать «Загрузить фото», выбрать фото любой вещи. Через несколько секунд в поле «Вещь» должно появиться описание.

Если появляется «Сервис разбора фото сейчас недоступен» — значит где-то на шагах 1-3 что-то не досохранилось; проверить, что ключ вставлен без пробелов и что был именно **redeploy** после сохранения переменных (просто сохранить их недостаточно — они подхватываются только при следующей сборке).

---

**Важно:** файл `certs/russian_trusted_root_ca.pem` — обязательная часть проекта для этой функции (без него GigaChat не даст с собой соединиться), удалять и перемещать его нельзя.
